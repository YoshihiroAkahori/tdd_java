# TDD
## 大事な考え方: 実装より先にテストすべきことをコード化する
## 具体的な進め方
1. ToDoリストを作る
2. 超ハードコードかつ具体的なコードでいいので、テストを実装する
3. テストがロジックで以前のレベルでエラーになることを確認する
4. ロジックを実装してテストが通ることを確認する
5. リファクタリングにより抽象化していく

## 通貨実装の流れ
1. ドルクラスの値を2倍にする機能を実装
2. 2倍にする機能を掛け算にする機能に抽象化
3. ドルクラスの値とドルクラスの値を比較する機能を実装
4. 掛け算機能では新しいクラスを生成させるように変更
5. ドルクラス同士で値を比較できる機能を実装
6. クラス外で使わないpropertyをprivate化
7. フランクラスをドルクラスコピペで実装
8. 抽象化されたマネークラス作成に向けて、空のマネークラスを作ってみる
9. ドル、フランがマネークラス（空）を継承するようにしてみる
10. 継承するために、protected propertyとしてamountをマネーに移管
11. Moneyクラスからdollar or francメソッドでそれぞれのクラスを呼び出せるようにする
12. 各サブクラスに通過単位を呼び出すcurrencyメソッドを実装
13. 親クラスに抽象メソッドとして、currencyメソッドを実装
14. 親クラスを抽象クラスに変更
13. 各サブクラスに通過単位をprivate定数として実装
14. currencyメソッドが共通しているので、親のマネークラスに昇格
